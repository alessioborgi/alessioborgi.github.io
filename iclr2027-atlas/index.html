Import review-level CSV

Use a local export if direct API access is restricted. Required columns: paper_id,title,rating,confidence. Optional: review_id,number,area,status,url.

How rankings are calculated. Each paper's score is the arithmetic mean of its valid numeric official reviewer ratings. The optional weighted score is Σ(rating × confidence) / Σ(confidence), using reviews with positive confidence. Equal scores share a rank. Withdrawn, desk-rejected and rejected papers are excluded by default. All comparisons are unofficial and are not acceptance predictions.
