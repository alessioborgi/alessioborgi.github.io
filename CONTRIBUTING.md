Contributions are welcome! 

For an ML Blog article centred on a specific paper, include the paper's actual
first-page preview after the opening TL;DR or paper information box. Register
its title, authors, source URL, PDF URL, local preview image, and image dimensions
in `_data/paper_previews.yml`, then use
`{% include paper-preview.html paper="the-paper-key" %}`. Check the title and
authors against the original PDF; an architecture figure does not replace the
first-page preview. Keep general tutorials and multi-paper surveys distinct from
articles about a single paper, and preserve existing publication settings.

Please add issues and make pull requests. There are no stupid questions. All ideas are welcome. This is a volunteer project. Be excellent to each other.

Bug reports and feature requests to the template  should be [submitted via GitHub](https://github.com/academicpages/academicpages.github.io/issues/new/choose). For questions concerning how to style the template, please feel free to start a [new discussion on GitHub](https://github.com/academicpages/academicpages.github.io/discussions).

Fork from master and go from there. Remember that this repository is intended to remain a generic, ready-to-fork template that demonstrates the features of academicpages.
